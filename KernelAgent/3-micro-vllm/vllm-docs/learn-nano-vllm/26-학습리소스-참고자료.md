# 학습 리소스 및 참고자료 (nano-vllm 및 추론 공학)

> **대규모 언어 모델 추론을 체계적으로 습득**하고자 하는 학습자를 위해: 먼저 전체적인 그림을 잡고, 그 다음 모듈별로 깊이 파고들며, 마지막으로 논문과 공식 문서를 통해 이론의 경계를 보완합니다.

---

## 1. nano-vllm 권장 학습 경로 (순서대로)

1. **진입점 및 설정**  
   `example.py`, `nanovllm/config.py`를 읽으며, `gpu_memory_utilization`, `max_num_batched_tokens`, `max_num_seqs`, `tensor_parallel_size` 등의 파라미터가 동작에 미치는 영향을 이해합니다.

2. **엔진 루프**  
   `LLMEngine`: `add_request` → `step` → `scheduler.schedule` → `model_runner.run` → `postprocess`. "한 번의 step이 무엇을 하는지"에 대한 멘탈 모델을 구축합니다.

3. **시퀀스 및 스케줄링**  
   `Sequence`(길이, `block_table`, `num_cached_tokens`)와 `Scheduler`(prefill 우선, decode, `preempt`). 강의 문서의 시퀀스 다이어그램과 대조하면 더욱 좋습니다.

4. **KV Cache와 Block**  
   `BlockManager`(xxhash 체인 해시, `allocate`/`deallocate`/`may_append`)와 `ModelRunner.allocate_kv_cache`(텐서 형상 및 블록 수 계산).

5. **어텐션과 FlashAttention**  
   `layers/attention.py`: `store_kvcache` + `flash_attn_varlen_func` / `flash_attn_with_kvcache`, `utils/context.py`의 `cu_seqlens_*`, `slot_mapping`, `block_tables`와 결합하여 이해합니다.

6. **텐서 병렬화**  
   `layers/linear.py`, `layers/embed_head.py`, `models/qwen3.py`: 컬럼 병렬, 로우 병렬, QKV 통합, LM Head의 `gather`.

7. **CUDA Graph**  
   `ModelRunner.capture_cudagraph`와 `run_model`의 prefill / decode 분기, `graph_bs`와 `enforce_eager` 이해.

8. **RoPE 및 모델 블록**  
   `rotary_embedding.py`, `Qwen3DecoderLayer`의 Pre-Norm + residual, `SwiGLU`(`SiluAndMul`).

9. **샘플링 및 엔지니어링 디테일**  
   `Sampler`(Gumbel-max 기법), `SamplingParams`(온도 하한), `loader.py`(safetensors + `packed_modules_mapping`).

**매 단계마다 로컬에서 단일 단계 디버깅을 하거나 텐서 shape을 출력해 보는 것을 권장**합니다. 읽기만 하고 쓰지 않는 것보다 훨씬 빠르게 직관을 쌓을 수 있습니다.

## 3. 사전 지식 학습 리소스

### 1. PyTorch

- 공식 문서: [https://pytorch.org/docs/stable/index.html](https://pytorch.org/docs/stable/index.html)  
- 핵심: `torch.nn`, `autograd` 기초, `Distributed` 개념, CUDA 텐서의 메모리 및 스트림 (Graph 및 비동기 복사 이해를 위한 기반).

### 2. CUDA

- NVIDIA CUDA C++ Programming Guide  
- 핵심: grid/block/thread, 공유 메모리, 병합 접근; 처음부터 큰 커널을 작성할 필요는 없으며, **Triton 및 PyTorch 확장**을 읽을 수 있으면 nano-vllm과 호환됩니다.

### 3. Transformer

- 고전적인 블로그 및 비디오 (Attention Is All You Need 도해)  
- 핵심: 셀프 어텐션 복잡도, 디코딩 단계에서의 KV Cache 의미, RoPE와 위치 정보의 관계.

## 4. 추천 도서 (선택 사항)

- 《딥러닝》(Goodfellow 등) — 기초 및 최적화.  
- 《Programming Massively Parallel Processors》(GPU 아키텍처)  
- 《Systems for Machine Learning》계열 강의록 — 추론 시스템 및 스케줄링 (각 대학 공개 강의)

도서는 **장기적인 보충 자료**이며, 단기적으로는 **프로젝트 + 논문 + 공식 문서**를 중심으로 하는 것이 더 효율적입니다.

## 6. 공식 및 생태계 문서

- **vLLM 공식 문서**: [https://docs.vllm.ai/](https://docs.vllm.ai/) — 프로덕션급 기능이 가장 완비되어 있으며, nano-vllm을 "경량화된 대조군"으로 읽을 수 있습니다.  
- **FlashAttention** (Dao-AILab): [https://github.com/Dao-AILab/flash-attention](https://github.com/Dao-AILab/flash-attention) — API, `varlen`, KV cache 통합에 관한 설명.  
- **Hugging Face Transformers / 모델 카드** — Qwen3 등 설정 항목과 가중치 명명 규칙, `packed_modules_mapping`과 대조.

## 7. 학습 리듬 제안

- **1주차**: 예제를 실행하고, `LLMEngine` + `Scheduler` 주요 경로를 따라갑니다.  
- **2주차**: KV + Block + Attention, prefill/decode 데이터 준비의 차이를 구술할 수 있도록 합니다.  
- **3주차**: TP + RoPE + Sampler, `qwen3.py`와 `linear.py`를 대조하며 그림을 그릴 수 있도록 합니다.  
- **지속적으로**: vLLM 해당 모듈과의 차이점(프리픽스 캐시, 더 완전한 스케줄링)을 읽으며, 비교 노트를 작성합니다.

**"말할 수 있고 + 소스 코드를 짚을 수 있고 + 그림 한 장을 그릴 수 있는"** 상태를 유지한다면, 면접이 훨씬 수월해질 것입니다.
