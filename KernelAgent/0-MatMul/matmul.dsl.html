<knowledge_rules>

<rule id="SM_Under_Occupancy_Alert">

Assert: if scheduling_policy == "persistent_cta" and num_ctas == 48: SM Pipeline Stalls occur during global memory loads.

Action: Increase num_ctas to 192 (4 blocks per SM). This allows the hardware warp scheduler to switch to other active warps and hide global memory latency.

<rule id="L2_Cache_Swizzling_Tuning">

Assert: if swizzling_policy == "grouped_l2_swizzle" and group_size_m == 4: Sub-optimal cache reuse on large L2 cache of Blackwell GPU.

Action: Set group_size_m = 8 to exploit the 48.0 MB L2 Cache residency, maximizing consecutive CTA block loads of B matrix tiles.

<rule id="Boundary_Padded_Index_Calculation">

Assert: if swizzling_policy == "grouped_l2_swizzle" and total_tiles != (num_groups * group_size_m * num_bid_n): Non-divisible matrix shapes trigger memory boundary bugs and incorrect calculations.

Action: Calculate total_tiles using group padding logic: total_tiles = num_groups * GROUP_SIZE_M * NUM_BID_N. Inside the kernel, add boundary check "if bid_m >= NUM_BID_M or bid_n >= NUM_BID_N: continue" to ensure correctness.

<milestones>

<stage id="1_matmul_sample" complexity="Low">

표준 그리드 맵핑 방식의 기본 cuTile 커널

특징: Grid size를 필요한 블록 수와 1대1 매핑하여 호출. 스케줄링이 단순하지만 런치 오버헤드와 L2 캐시 지역성을 제어하지 못함.

<code_primitive lang="python">
@ct.kernel
def matmul_sample(A, B, C, NUM_BID_M: int, NUM_BID_N: int, NUM_K_TILES: int):
    # Standard grid mapping using bid(0) for m and bid(1) for n
    bid_m = ct.bid(0)
    bid_n = ct.bid(1)

    acc = ct.zeros((64, 64), dtype=ct.float32)

    for k in range(NUM_K_TILES):
        tile_A = ct.load(A, index=(bid_m, k), shape=(64, 64))
        tile_B = ct.load(B, index=(k, bid_n), shape=(64, 64))

        tile_A = ct.astype(tile_A, ct.float16)
        tile_B = ct.astype(tile_B, ct.float16)

        acc = ct.mma(tile_A, tile_B, acc=acc)

    ct.store(C, index=(bid_m, bid_n), tile=ct.astype(acc, C.dtype))

<stage id="2_matmul_tilegym" complexity="High">

고정 persistent grid 스케줄링 및 L2 Cache Swizzling이 적용된 최적화 커널

특징: num_ctas=192 고정 그리드 가동. 그룹 스위즐링을 통해 B 행렬 로드 시 L2 캐시 재사용성을 극대화하고 경계 버그 방어 수식을 통합.

<code_primitive lang="python">
@ct.kernel
def matmul_tilegym(A, B, C, NUM_BID_M: int, NUM_BID_N: int, NUM_K_TILES: int, GROUP_SIZE_M: int):
    # Persistent Thread Scheduling
    start_tile_id = ct.bid(0)
    num_programs = ct.num_blocks(0)
    num_groups = (NUM_BID_M + GROUP_SIZE_M - 1) // GROUP_SIZE_M
    total_tiles = num_groups * GROUP_SIZE_M * NUM_BID_N

    for tile_id in range(start_tile_id, total_tiles, num_programs):
        # Grouped L2 Cache Swizzling (M-fast, N-slow layout)
        tiles_per_group_strip = GROUP_SIZE_M * NUM_BID_N
        group_id = tile_id // tiles_per_group_strip
        group_offset = tile_id % tiles_per_group_strip
        
        bid_n_inner = group_offset // GROUP_SIZE_M
        bid_m_inner = group_offset % GROUP_SIZE_M
        
        bid_m = group_id * GROUP_SIZE_M + bid_m_inner
        bid_n = bid_n_inner

        if bid_m >= NUM_BID_M or bid_n >= NUM_BID_N:
            continue

        acc = ct.zeros((64, 64), dtype=ct.float32)

        for k in range(NUM_K_TILES):
            tile_A = ct.load(A, index=(bid_m, k), shape=(64, 64))
            tile_B = ct.load(B, index=(k, bid_n), shape=(64, 64))

            tile_A = ct.astype(tile_A, ct.float16)
            tile_B = ct.astype(tile_B, ct.float16)

            acc = ct.mma(tile_A, tile_B, acc=acc)

        ct.store(C, index=(bid_m, bid_n), tile=ct.astype(acc, C.dtype))
