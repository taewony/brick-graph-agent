<knowledge_rules>

<rule id="Launch_Overhead_Warning">

Assert: if execution_mode == "eager" and kernel_launch_count > (num_layers * 2): CPU launch latency dominates E2E time.

Action: Apply 'CUDA Graph' for decode phase, or integrate all operations into a single 'Super Fusion' kernel to minimize launch count.

<rule id="Register_Pressure_Defense">

Assert: if prefill_tile_m == 128 or prefill_tile_n == 128: Register spilling triggers L1/VRAM overhead.

Action: Force prefill_tile_m = 64 and prefill_tile_n = 64. Use online softmax to reduce intermediate register allocations.

<rule id="Decode_Attention_Routing">

Assert: if query_length == 1 (Decoding Phase): Using GEMM-based FMHA kernel causes SM Starvation and quadratic calculations.

Action: Route to GEMV-based FlashDecoding. Dynamically set split_cta based on sequence length: seq_len < 128 (split_cta=1), 128-512 (split_cta=2), 512+ (split_cta=4).

<rule id="Allocator_Thrashing_Prevention">

Assert: if execution_mode == "eager" and use_dynamic_shape_padding == True: Frequent dynamic allocations thrash PyTorch Caching Allocator and trigger Python GC.

Action: Avoid dynamic shape padding in Eager mode. Maintain eager unpadded shape allocation, or pre-allocate static shape buffers when using CUDA Graphs.

<rule id="SM_Partitioning_Rule">

Assert: if active_prefills >= 1 and active_decodes >= 1 and target_median_ITL_drop == True: Compute-heavy prefills starve latency-sensitive decodes.

Action: Enable sm_partitioning="green_contexts" with ratio count (32 SM prefill / 16 SM decode) to secure L2 Cache residency for decode kernels.

<milestones>

<stage id="1_GEMM" complexity="Low">

Matrix Multiplication (MatMul) 최적화 단계

병목 (Bottleneck): Shared memory bank conflicts and register occupancy limits.

해결 (Solution): Implement tiled GEMM with cuTile, loading sub-matrices into shared memory.

<code_primitive lang="python">
# cuTile Tiled MatMul Kernel Example
@ct.kernel(occupancy=2)
def gemm_kernel(A, B, C, TILE_M: ConstInt, TILE_N: ConstInt, TILE_K: ConstInt):
    tx = ct.threadIdx(0)
    ty = ct.threadIdx(1)
    # Load blocks to Shared Memory and compute MMA
    a_tile = ct.load(A, index=(ct.bid(0) * TILE_M, 0))
    b_tile = ct.load(B, index=(0, ct.bid(1) * TILE_N))
    acc = ct.mma(a_tile, b_tile)
    ct.store(C, index=(ct.bid(0) * TILE_M, ct.bid(1) * TILE_N), tile=acc)

<stage id="2_FMHA" complexity="Medium">

Fused Multi-Head Attention (FMHA) 통합 설계 단계

병목 (Bottleneck): Memory-bandwidth limit due to intermediate attention matrix write-back.

해결 (Solution): Fuse attention computation by storing intermediate scores in register tiles; apply causal mask and scale online.

<code_primitive lang="python">
# Online softmax and causal masking inside cuTile prefill loop
for j in range(0, Tc):
    k = ct.load(K, index=(batch_idx, off_kv_h, 0, j), shape=(1, 1, TILE_D, TILE_N)).reshape((TILE_D, TILE_N))
    qk = ct.full((TILE_M, TILE_N), 0., dtype=np.float32)
    qk = ct.mma(q, k, qk)
    if CAUSAL and j >= mask_start:
        offs_n = j * TILE_N + offs_n_tile
        mask = ct.where(offs_m >= offs_n, 0.0, -np.inf)
        qk += mask
    # Online softmax reduction
    m_ij = max(m_i, ct.max(qk, axis=-1, keepdims=True) * qk_scale)
    qk = qk * qk_scale - m_ij
    p = ct.exp2(qk, flush_to_zero=True)
    l_ij = ct.sum(p, axis=-1, keepdims=True)
    alpha = ct.exp2(m_i - m_ij, flush_to_zero=True)
    l_i = l_i * alpha + l_ij
    acc = acc * alpha

<stage id="3_Single_User_LLM" complexity="High">

Single User LLM Inference (llm-from-scratch) 최적화 단계

병목 (Bottleneck): High Python runtime launch overhead (ct.launch ctypes costs) in token-by-token decoding.

해결 (Solution): Record and replay the decode execution path using CUDA Graphs with static pre-allocated memory buffers.

<code_primitive lang="python">
# CUDA Graph Capture and Replay for Decode Loop
static_input = torch.zeros(batch_size, dtype=torch.int64, device='cuda')
static_kv_cache = torch.zeros(layers, batch_size, seq_len, head_dim, device='cuda')
static_logits = torch.zeros(batch_size, vocab_size, device='cuda')

# Warmup execution
for _ in range(3):
    outputs = model(static_input, static_kv_cache)

# Capture into Graph
g = torch.cuda.CUDAGraph()
with torch.cuda.graph(g):
    static_logits.copy_(model(static_input, static_kv_cache))

# Generation loop replay
for step in range(max_new_tokens):
    static_input.copy_(next_token_tensor)
    g.replay()
    next_token_tensor.copy_(sample(static_logits))
