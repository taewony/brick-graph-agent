<knowledge_rules>

<rule id="Dispatch_Overhead_Evasion">

Assert: if sequence_length < 4096 and use_pytorch_sdpa == True: Complex dynamic dispatcher (FlashAttention vs memory-efficient fallback selection) causes framework overhead.

Action: Use cuTile's direct JIT kernel compilation. Run as a single, lightweight CUDA launch with zero dispatch checks to secure up to 2x speedup.

<rule id="Register_Occupancy_Balancing">

Assert: if tile_m > 64 or tile_n > 64: High register pressure causes L1/VRAM spilling.

Action: Constrain tile dimensions to 64x64. Balance intermediate matrix variables to maximize concurrent thread block occupancy on all 48 SMs.

<rule id="Pipelined_Latency_Hiding">

Assert: if use_pipelined_prefetching == False: High-latency DRAM global memory reads stall Tensor Core matrix multiplications (ct.mma).

Action: Set latency=2 for loading Query(Q) and Key(K) tiles (prefetch to registers/SRAM), and set latency=4 for loading Value(V) tiles (overlap global DRAM reads with current QK^T arithmetic execution).

<rule id="Causal_Loop_Bounding_Optimization">

Assert: if attention_masking == "causal" and use_dynamic_loop_bounding == False: Calculating the upper-triangular masking elements wastes 50% of FLOPs.

Action: Compute the lower-triangular portion of the attention matrix. Dynamically bound the loop limit: Tc = ct.cdiv(min(m_end, k_seqlen), TILE_N). This achieves a near-perfect 1.92x execution time reduction compared to non-causal.

<rule id="Attention_Memory_Bound_Insight">

Assert: if attention_masking == "non_causal" and sequence_length >= 1024: PyTorch SDPA performance degrades due to high pointwise memory traffic (softmax, scaling).

Action: Rely on cuTile's online fused softmax. Unlike pure compute-bound MatMul (which saturates at 90% of cuBLAS), FMHA maintains a stable 2.0x speedup up to 4096x4096 by keeping attention scores entirely inside the SM registers.

<stage id="1_Non_Causal_FMHA" complexity="Medium">

온라인 소프트맥스와 L2 캐시 파이프라이닝이 융합된 Fused Attention

특징: QK^T 연산과 V 곱셈을 온칩 SRAM 내에서 연속 수행하여 DRAM 메모리 트래픽을 차단. Q, K, V에 latency 힌트 적용.

<code_primitive lang="python">
# Load Q tile
q = ct.load(
    Q, index=(batch_idx, head_idx, bid_x, 0), shape=(1, 1, TILE_M, TILE_D),
    padding_mode=ct.PaddingMode.ZERO, latency=2
).reshape((TILE_M, TILE_D))

# Inner loop over K, V tiles
for j in range(0, Tc):
    k = ct.load(
        K, index=(batch_idx, off_kv_h, 0, j), shape=(1, 1, TILE_D, TILE_N),
        order=(0, 1, 3, 2), padding_mode=ct.PaddingMode.ZERO, latency=2
    ).reshape((TILE_D, TILE_N))
    
    qk = ct.full((TILE_M, TILE_N), 0., dtype=np.float32)
    qk = ct.mma(q, k, qk)
    
    # Online Softmax update
    m_ij = max(m_i, ct.max(qk, axis=-1, keepdims=True) * qk_scale)
    qk = qk * qk_scale - m_ij
    p = ct.exp2(qk, flush_to_zero=True)
    l_ij = ct.sum(p, axis=-1, keepdims=True)
    alpha = ct.exp2(m_i - m_ij, flush_to_zero=True)
    
    l_i = l_i * alpha + l_ij
    acc = acc * alpha
    
    # Load V tile
    v = ct.load(
        V, index=(batch_idx, off_kv_h, j, 0), shape=(1, 1, TILE_N, TILE_D),
        padding_mode=ct.PaddingMode.ZERO, latency=4
    ).reshape((TILE_N, TILE_D))
    
    p = p.astype(Q.dtype)
    acc = ct.mma(p, v, acc)
    m_i = m_ij
